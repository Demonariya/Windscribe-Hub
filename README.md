# Windscribe Pro

**Version:** 0.0.1  
**Platform:** Windows 10 / Windows 11 (x64)  
**Language:** Rust  
**UI:** eframe / egui  
**License:** MIT

Windscribe Pro is a native Windows desktop utility for the Windscribe desktop app and Windscribe account credentials.

## Features

### Install and process status
- Checks the exact WinGet package ID: \`Windscribe.Windscribe\`.
- Also checks Windows uninstall registry entries and common install paths. A local installation is not treated as missing just because it was not installed through WinGet.
- Checks for WinGet upgrades only when the app is managed by WinGet.
- Presents Install, Update, or Open based on detected state.
- Detects whether \`Windscribe.exe\` is running.
- Performs package operations on a worker thread to keep the interface responsive.

### Windscribe account vault
- Stores multiple Windscribe username/password pairs.
- Reveals or hides each saved password independently.
- Loads a selected account into the editor and copies username/password.
- Updates an existing entry when the same username is saved again.
- Generates a username suggestion and a strong random password.
- Encrypts the vault with Windows DPAPI for the current Windows user.

### Registry cleanup
The two requested keys are supported:
1. \`HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\NetControlPort\`
2. \`HKCU\\Software\\Windscribe\\Windscribe2\`

Each operation requires confirmation, verifies the key exists, exports a timestamped \`.reg\` backup, and only then deletes it.

## Build from source

Install the stable Rust toolchain and Visual Studio C++ Build Tools (MSVC) with the Windows SDK.

\`\`\`powershell
cargo build --release
\`\`\`

Executable:

\`target\\release\\windscribe-pro.exe\`

The Windows executable icon is generated by \`build.rs\` and embedded in the binary.

## Encrypted credential storage

The vault is stored at:

\`%LOCALAPPDATA%\\WindscribeHub\\accounts.vault\`

Windows DPAPI protects the data for the current Windows user. The vault is not portable to another Windows account or machine. Never commit real credentials or the vault file to Git.

A generated username is a suggestion only. This app does not create Windscribe accounts or verify credentials with Windscribe servers.

## Registry backups

\`%USERPROFILE%\\Documents\\Windscribe Hub\\Backups\`

## CI

GitHub Actions builds the Windows x64 executable on pushes to \`main\`, version tags (\`v*\`), pull requests, and manual dispatch. The executable is uploaded as a workflow artifact.

## 0.0.1 limitations

- WinGet is required for installation and reliable update checks.
- Non-WinGet installations can be detected and opened, but their update state cannot be queried through WinGet.
- The running-state check looks for the Windows process \`Windscribe.exe\`.
- Runtime validation on different Windows installations is still required.
